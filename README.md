# ShiftManager
An application managing shifts of employees.

Course project for *Introduction to Software Engineering* (HCMUS), team 404NotFound (T06).
The repository currently holds the phase deliverables; application code is not written yet.

## Repository structure

```
pa/                     Phase submissions (T06-PA0 to T06-PA3, .docx and .pdf)
docs/
  ai-usage/             AI usage log of each phase
  design/
    adr/                Architecture Decision Records (PA3)
    figures/            PA3 diagram sources (.drawio) and exports (.png)
  management/           WBS, Gantt chart and weekly status reports
backend/  frontend/     Reserved for the implementation (PA5)
```
